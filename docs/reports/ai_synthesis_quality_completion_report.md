## 1. Root Causes Discovered & Fixed

### 1.1 Flawed Subject Detection & Cross-Domain Contamination
- **Root Cause**: `_detect_syllabus_subject` used a basic substring scan on `text[:4000]`. In Computer Networks notes, page 2 contained *"process-to-process communication in Transport Layer"*. The word `'process'` triggered the Operating Systems branch, causing the Big Picture synthesis and entity classifiers to inject CPU scheduling and deadlock paragraphs.
- **Architectural Fix**:
  1. Replaced with `detect_document_identity_and_subject(text, title)` featuring title-level trigger priority and weighted keyword scoring across the complete text.
  2. Implemented `validate_subject_consistency(text, detected_subject)` with explicit forbidden lists: for `Computer Networks`, terms like `'cpu scheduling'`, `'deadlock'`, `'demand paging'`, `'virtual memory'` are strictly disallowed and pruned from synthesis outputs.

### 1.2 Formula Truncation via Period-Splitting Regex
- **Root Cause**: The formula parser used regex `r'...\s*=\s*([^;\.\n]{1,90})'`. The character class `[^;\.\n]` treated the decimal point in `0.04` as a sentence-ending period, cutting `0.04` into `0`. This corrupted the Bandwidth-Delay Product equation into:
  $$\text{BDP} = 100 \times 10^6 \times 0$$
- **Architectural Fix**:
  Implemented decimal-aware lookahead regex:
  ```python
  (?:[^\.\n;]|(?<=\d)\.(?=\d))+
  ```
  Added `validate_formula_fidelity` to ensure equations retain valid multi-term derivations, decimal multipliers, and correct unit suffixes ($\text{b/s}$, $\text{ms}$, $\text{bytes}$).

### 1.3 Generic "System Algorithm" Renaming
- **Root Cause**: In `_parse_section_elements`, whenever the word `algorithm` appeared outside four hardcoded Automata algorithms, it fell back to `algo_name = "System Algorithm"`, renaming Dijkstra's Algorithm into `System Algorithm`.
- **Architectural Fix**:
  Implemented `detect_grounded_algorithm_name(sentence, title, subject)`:
  - Specifically matches grounded networking algorithms: Dijkstra's SPF, Bellman-Ford, CRC Division, Hamming Code SEC, CSMA/CD Backoff, TCP Reno AIMD, and VLSM.
  - If no technical algorithm name is verified from the text, returns `None` rather than inventing a placeholder.

### 1.4 Literal `undefined` Rendered in Frontend & API
- **Root Cause**: In `Upload.jsx` and `MySummaries.jsx`, `handleCopySummary` directly concatenated `it.definition`. In concept cards generated by `format_pedagogical_concept`, the primary definition was stored in `def` or `in_depth`. Accessing `it.definition` yielded JavaScript `undefined`, resulting in:
  `1.1 What is a computer network?: undefined`
- **Architectural Fix**:
  1. Updated frontend copy handlers with safe fallback chains:
     ```javascript
     const detail = it.definition || it.def || it.in_depth || it.meaning || it.intuition || it.detail || it.title || '';
     if (detail) fullText += `• ${it.term || it.concept || it.label || it.title}: ${detail}\n`;
     ```
  2. Enriched backend API response items in `api/views.py` so both `definition` and `def`, `title` and `label` are populated.
  3. Added an automated sanitization pass in `_synthesize_grounded_markdown_explanation`:
     ```python
     res_md = re.sub(r':\s*undefined\b', '', res_md)
     res_md = re.sub(r'\b(?:undefined|null|None|NaN|\[object Object\])\b', '', res_md)
     ```

### 1.5 Flattened 87 Sections vs. 17 Core Chapters
- **Root Cause**: Numbered subheadings `1.1`, `1.2`, ..., `14.4` were parsed as independent top-level modules. Lines matching `15.`, `16.`, `17.` had no decimal point, so Chapters 15, 16, and 17 were skipped as sections, while IP addresses like `192.0.2.10` were misidentified as section `192.0`.
- **Architectural Fix**:
  1. Implemented two-pass heading recognition: scans document lines to extract `chapter_map` (discovering all 17 chapters from Chapter 1 to Chapter 17).
  2. IP address filter rejects lines starting with 3 or more dot-separated numbers (`192.0.2.10`).
  3. Sections attach to their respective chapters: `1.1` to `Chapter 1: Network Fundamentals and Performance`, `8.5` to `Chapter 8: Network Layer, IPv4 Addressing and Subnetting`.
  4. Chapters 15, 16, 17 are preserved as major sections with their full content:
     - Chapter 15: High-yield formula sheet & common traps (2,512 characters).
     - Chapter 16: Original GATE-style practice set with solutions (3,284 characters).
     - Chapter 17: Final revision checklist (1,888 characters).
