StudyAI Platform

StudyAI is a full-stack React 19 + Vite + Django application. The VS Code Live Server extension is a static HTML server that cannot compile React JSX components directly.

🚀 Open Vite App (Port 5173) 📦 Open Built Bundle (dist/)
👉 1-Click Launch Options:
1. Double-click: GO_LIVE.bat in the project folder (starts everything + opens browser)
2. In VS Code: Press F5 or Ctrl + Shift + B
3. Or in Terminal: npm start
